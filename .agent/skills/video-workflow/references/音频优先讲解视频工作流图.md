# 音频优先的讲解视频工作流图

图中保留默认 Shotcut 路径，并加入当前已授权的 AI 样片草剪路径。录音者先看一条 MP4 并集中反馈；明确验收样片后，才进入全片流程。剪辑清单、字幕分行和画面时间清单保存在当前 run 的忽略目录，由 `media_tools.py` 执行；页面图片本身不含字幕。

~~~mermaid
flowchart TD
    A["登记录音、受众、用途及可选参考资料/必讲清单"] --> B{"已有样片产物？"}
    B -->|有| C["接管现有样片，核对路径和哈希；不重跑"]
    B -->|无| D["准备开头连续 3 分钟样片：Qwen 转写、静音粗剪"]
    C --> E["生成 Markdown 页面大纲初稿"]
    D --> E
    E --> F["AI 复审最新大纲与内容问题，关联页面、cue 和补录项"]
    F --> G["默认路径：人工逐项决定"]
    G -->|有修订或待处理项| E
    G -->|问题已处理且大纲获批| H["Shotcut 审听、剪辑并录入获批补录"]
    E --> V["当前授权：AI 草剪前三分钟，图示素材不含字幕"]
    V --> W["合成内部 MP4：字幕作为独立图层叠加"]
    W --> X["录音者看视频并集中反馈一次"]
    X -->|确认内容后| Y["AI 定稿样片音轨并登记 ai_audio_export"]
    Y --> I
    H --> I["导出定稿音轨；重新转写、校对并用 Qwen ForcedAligner 对齐"]
    I --> J["更新页面与最终字幕映射"]
    J --> K["生成同步 MP4 或网页演示"]
    K --> L{"内容、同步和画面质量合格？"}
    L -->|时间、画面或可读性问题| K
    L -->|SRT 对齐问题且音轨未变| I
    L -->|发现口播或内容问题| F
    L -->|录音者明确验收| M["人工记录样片验收"]
    M --> N["处理完整录音并生成全片大纲"]
    N --> O["AI 复审全片大纲与内容"]
    O --> P["人工逐项处理并确认全片大纲"]
    P -->|仍有修改或待处理问题| O
    P -->|全片内容获批| Q["Shotcut 定稿全片音轨并录入获批补录"]
    Q --> R["导出全片定稿音轨；重新转写、校对和对齐"]
    R --> S["更新全片页面/字幕映射并生成同步演示"]
    S --> T{"全片质量检查通过？"}
    T -->|时间、画面或可读性问题| S
    T -->|口播或内容问题| O
    T -->|通过| U["完成"]
~~~

全量录音处理受样片验收 gate 控制。过期产物保留在本地，但必须重建后才能进入下游阶段。
