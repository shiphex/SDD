# 音频优先的讲解视频工作流图

图中保留默认 Shotcut 路径，并加入明确授权的 AI 样片、全片草剪和投稿准备路径。当前 `pilot` 样片与全片现有内容及听感已获用户接受，发布版和本地投稿包已交付，尚未上传。其他 run 仍先看内部 MP4 并集中反馈；明确验收样片后，才进入全片流程。剪辑、字幕和画面时间清单保存在当前 run 的忽略目录，由媒体工具执行；页面图片本身不含字幕。

~~~mermaid
flowchart TD
    A["登记录音、受众、用途及可选参考资料/必讲清单"] --> B{"已有样片产物？"}
    B -->|有| C["接管现有样片，核对路径和哈希；不重跑"]
    B -->|无| D["准备开头连续 3 分钟样片：Qwen 转写、静音粗剪"]
    C --> E["生成 Markdown 页面大纲初稿"]
    D --> E
    E --> F["AI 复审最新大纲与内容问题，关联页面、cue 和补录项"]
    F --> G["默认路径：人工逐项决定"]
    G -->|有修订或待处理项| E
    G -->|问题已处理且大纲获批| H["Shotcut 审听、剪辑并录入获批补录"]
    E --> V["当前授权：AI 草剪前三分钟，图示素材不含字幕"]
    V --> W["合成内部 MP4：字幕作为独立图层叠加"]
    W --> X["录音者看视频并集中反馈一次"]
    X -->|确认内容后| Y["AI 定稿样片音轨并登记 ai_audio_export"]
    Y --> I
    H --> I["导出定稿音轨；重新转写、校对并用 Qwen ForcedAligner 对齐"]
    I --> J["更新页面与最终字幕映射"]
    J --> K["生成同步 MP4 或网页演示"]
    K --> L{"内容、同步和画面质量合格？"}
    L -->|时间、画面或可读性问题| K
    L -->|SRT 对齐问题且音轨未变| I
    L -->|发现口播或内容问题| F
    L -->|录音者明确验收| M["人工记录样片验收"]
    M --> N["处理完整录音并生成全片大纲"]
    N --> O["AI 复审全片大纲与内容"]
    O --> AIF{"当前 run 明确授权 AI 全片？"}
    AIF -->|有授权| AID["AI 精修原声，重新转写对齐并制作内部完整 MP4"]
    AID --> AIFB["录音者集中反馈；内容问题与补录另列"]
    AIFB --> P["人工确认全片内容"]
    AIF -->|默认路径| P
    P -->|仍有修改或待处理问题| O
    P -->|Shotcut 路径内容获批| Q["Shotcut 定稿全片音轨并录入获批补录"]
    P -->|AI 路径内容获批| AIFINAL["AI 定稿全片音轨并登记 full_ai_audio_export"]
    AIFINAL --> R
    Q --> R["导出全片定稿音轨；重新转写、校对和对齐"]
    R --> S["更新全片页面/字幕映射并生成同步演示"]
    S --> T{"全片质量检查通过？"}
    T -->|时间、画面或可读性问题| S
    T -->|口播或内容问题| O
    T -->|通过| U["正式视频交付"]
    U --> PUB{"要求发布定稿或投稿材料？"}
    PUB -->|有要求| PUBBASE["核对当前基线与用户接受范围"]
    PUBBASE --> PUBVIS["清理全部独立画面状态；音轨未变则复用字幕与 AAC"]
    PUBVIS --> PUBCHECK["检查实际视频帧、连续解码和公开文件清单"]
    PUBCHECK --> PUBREADY["发布版可投稿；上传按明确授权与实际结果另行登记"]
~~~

全量录音处理受样片验收 gate 控制。过期产物保留在本地，但必须重建后才能进入下游阶段。

发布分支的具体基线、复用、打包及登记步骤见[发布定稿与投稿准备](发布定稿与投稿准备.md)。
