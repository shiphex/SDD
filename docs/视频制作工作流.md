# 音频优先的讲解视频工作流

更新日期：2026-10-01

## 1. 工作边界

先用录音开头连续 3 分钟制作样片。AI 负责提供转写、静音候选和待核对提示；用户在 Shotcut 中试听、调整剪辑并导出定稿音轨。只有样片通过人工审阅后，才决定是否继续处理完整录音。

原录音保持不变。录音副本、机器转写、对齐 JSON、字幕草稿、模型权重、粗剪工程和网页样片存放在 Git 忽略的 `.local/video/pilot/`。这些文件不进入提交或公开材料。

音频编辑会改变时间基线。剪辑或补录后，必须从导出的定稿音轨重新识别和对齐，再编写最终字幕与画面时间表。

## 2. 工具与版本

| 工具 | 固定版本或范围 | 用途 |
| --- | --- | --- |
| Qwen3-ASR / ForcedAligner | `qwen-asr==0.0.6`、Python 3.12、`torch==2.10.0+cu128`；模型分别为 `Qwen/Qwen3-ASR-0.6B` 与 `Qwen/Qwen3-ForcedAligner-0.6B` | 中文识别和真实字/词级对齐时间戳，由音频技能自己的 UV 项目和 `uv.lock` 管理 |
| Auto-Editor | 官方 Windows 版 `31.6.0` | 按响度寻找静音，使用 `--margin 0.2s --export v2` 输出可检查的时间线候选；不自动定稿 |
| CLI-Anything Shotcut | `cli-anything-shotcut==1.0.0`、Python 3.12 | 在独立 UV 项目中生成或检查 MLT 工程文件；不控制 Shotcut 图形界面 |
| web-video-presentation | 上游 `v1.2.2` 技能及随附 MIT 许可 | 提供主题和网页演示方法；本地适配增加 PowerShell 脚手架与已有音轨同步模板 |

Qwen 的 0.6B 模型不预设能达到 Whisper medium 的识别质量。锁定包的强制对齐路径按不超过 180 秒的段落处理长音频，并合并时间偏移；本机检查 `qwen-asr==0.0.6` 的实现常量为 180 秒。更换包版本后，应重新检查分段和合并逻辑。

模型卡和 Qwen 推理包采用 Apache-2.0 许可；Auto-Editor Windows 工具按上游 Unlicense 发布；CLI-Anything Shotcut Python 包在 PyPI 标注 MIT。上游许可文件随复制或适配的技能保留。Auto-Editor 使用官方 Windows 可执行文件，因为上游当前不再提供 PyPI 包。

当前不安装 WhisperX。Qwen 已同时提供中文识别与配套对齐器；引入第二套识别和对齐依赖会增加维护面，样片校对后再评估是否需要对照基线。

## 3. 样片准备

从仓库根目录的 PowerShell 运行：

```powershell
.\.agent\skills\audio-to-srt\scripts\prepare-pilot.ps1
```

默认读取忽略目录中的本机 `tool-paths.json`。也可以显式传入录音路径：

```powershell
.\.agent\skills\audio-to-srt\scripts\prepare-pilot.ps1 -InputAudio <录音路径>
```

脚手架会准备开头连续 180 秒的单声道 16 kHz WAV、Qwen 原时间码 SRT 和对齐 JSON、Auto-Editor v2 候选、A/B/C 审阅清单及 Shotcut MLT 粗剪工程。时间码均以未剪辑样片为基准。A 项是静音候选；B 项需要对照录音核对表达、术语和顺序；C 项记录试听后才可确认的补录需要。识别稿只作为校对起点。

使用 `-SkipTranscription` 可在模型未安装或暂不识别时只准备音频候选和 MLT 工程。需要时通过下列入口单独生成原始转写：

```powershell
.\.agent\skills\audio-to-srt\scripts\run-audio-to-srt.ps1 `
  .local\video\pilot\source-first-3m.wav `
  --language Chinese `
  --output .local\video\pilot\source.srt `
  --json-output .local\video\pilot\source.alignment.json
```

## 4. Shotcut 人工定稿

在 Shotcut 中打开 `.local/video/pilot/roughcut-candidate.mlt`，逐个试听自动切点附近的停顿、呼吸和句间衔接。保留、移动或删除切点由人决定。不要以 MLT 成功生成或静音检测结果代替试听。

编辑完成后，从 Shotcut 导出定稿音轨至 `.local/video/pilot/`，并在 `edit-review.md` 记录采用项、保留项、补录和关键术语的人工抽听结果。样片通过后再处理完整录音。

## 5. 定稿字幕与网页演示

对 Shotcut 导出的定稿音轨重新运行 Qwen 与 ForcedAligner：

```powershell
.\.agent\skills\audio-to-srt\scripts\run-audio-to-srt.ps1 `
  .local\video\pilot\final-audio.wav `
  --language Chinese `
  --output .local\video\pilot\final.srt `
  --json-output .local\video\pilot\final.alignment.json
```

再依据校对后的 `final.srt` 和人工确认的画面提纲编辑 `timeline.json`。每个场景的 `start`、`end` 是相对于定稿音轨播放起点的秒数，场景按时间排序且不重叠。用 PowerShell 创建网页项目：

```powershell
.\.agent\skills\web-video-presentation\scripts\scaffold.ps1 `
  -Target .local\video\pilot\presentation `
  -AudioPath .local\video\pilot\final-audio.wav `
  -TimelinePath .local\video\pilot\timeline.json
```

网页中的播放、暂停、拖动与场景跳转共用一个音频播放头；当前画面按音频 `currentTime` 更新。网页不重写或合成旁白。用户可在 Shotcut 中复核并导出包含该音轨的成片。

## 6. 样片审阅门槛

- 原录音未被覆盖；样片、模型、转写、字幕和工程留在忽略目录。
- 对照录音核对专有名词、数字、切点、停顿和补录衔接。
- 定稿音轨可播放、暂停、跳转；网页画面跟随定稿音轨定位。
- 最终字幕和画面区间从定稿音轨重新对齐，没有沿用剪辑前时间戳。
- 人工抽听结果已记录，再决定是否处理完整录音。

模型大小不构成识别质量证据。准确度只依据样片人工校对结果评估；AI 生成的候选不自行改音频、确认事实或决定补录内容。
