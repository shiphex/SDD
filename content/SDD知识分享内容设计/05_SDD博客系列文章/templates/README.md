# 模板目录

模板用于开始书写，不是完成度清单。先阅读对应系列文章，再删除不适用章节；不要为了填满模板编造事实、阈值或决定。

| 模板 | 用途 |
| --- | --- |
| [01 Problem](01-problem模板.md) | 问题、目标、非目标和成功标准 |
| [02 Architecture](02-architecture模板.md) | 边界、职责、所有权和不变量 |
| [03 Runtime](03-runtime模板.md) | 主链、状态、事件和生命周期 |
| [04 Contracts](04-contracts模板.md) | 输入、输出、状态效果和失败语义 |
| [05 Failures](05-failures模板.md) | 失败分类、传播、恢复和最终状态 |
| [06 Decisions](06-decisions模板.md) | ADR、候选方案、取舍和验证 |
| [07 Test Plan](07-test-plan模板.md) | 测试分层、追踪矩阵和完成门槛 |
| [08 Tasks](08-tasks模板.md) | Current Facts、Gap、Task 和完成记录 |
| [Human Review](Human_Review模板.md) | 事实抽查、裁决与放行范围 |
| [Learning Review Card](Learning_Review_Card模板.md) | 个人判断对照和原则提炼 |

使用时遵守三条规则：

1. 当前事实附适用版本或观察证据；未知项明确标为未知。
2. Proposed、Accepted、Implemented 和 Verified 使用不同状态。
3. 低风险变化可以合并模板，但仍覆盖实际相关的信息。

`01–08` 各有一份字段模板；`09 Feedback` 根据评审目的分别使用 Human Review 或 Learning Review Card，不额外合并成一份重复模板。
