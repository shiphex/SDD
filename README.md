# SDD：用规范驱动可验证的软件增量

本仓库维护一套面向 AI 协作开发的个人 SDD（Spec-Driven Development）工作流，以及围绕这套方法编写的中文内容。它从目标和现状的差距出发，以可验证增量推进，并在设计变化后同步规范、实现与证据。

## 当前内容

- [SDD SKILL](skills/sdd/SKILL.md)：供 Codex 在调查、设计、规划、实施、评审和收尾任务中使用。
- [SDD 知识分享内容设计](content/SDD知识分享内容设计/context.md)：当前最新的内容设计基线，包含总览博客、`01–09` 系列文章、模板、工作底稿和演示大纲。
- [SDD 学习实战笔记 V2](content/SDD学习实战笔记V2/00_SDD总览与文档地图.md)：最新文稿引用的方法知识资料。

## 仓库结构

- `content/`：当前文稿与方法知识资料。
- `skills/`：可供 Codex 使用的 SDD Skill。
- `docs/`：项目方案、内容规范和公开来源索引。

原始笔记、历史聊天、旧版本发布稿和内部迁移记录只在本机归档，不进入 Git。仓库不包含可运行的教学项目或案例测试结果。
